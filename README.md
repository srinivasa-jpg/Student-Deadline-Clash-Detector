# Student Deadline Clash Detector

A visual academic workload tool that detects deadline conflicts before they become a problem.

## Features
- Add assignments, exams, projects, presentations and submissions
- Priority and estimated-effort scoring
- Automatic same-day clash detection
- Back-to-back high-priority deadline detection
- 7-day pressure forecast
- Light / Busy / Overloaded day classification
- Upcoming, completed and type filters
- Mark deadlines complete or delete them
- Responsive mobile interface
- Local browser persistence

## How pressure works
Each deadline contributes a priority score (1–3) plus an effort score (1–3). Multiple deadlines and high combined workload increase the day's pressure classification. The detector also flags high-priority items on consecutive days.
